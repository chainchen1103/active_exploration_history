# 主動探索研究計畫歷程記錄  
一個用於紀錄與歸檔關於**任務導向的成本感知視觸覺主動探索**研究的資料倉庫  
  
## 研究目標  
建立任務導向的視觸覺主動探索策略。並討論在複雜環境導致的視覺退化下的泛化能力。  
  
## repo 結構  

```
任務導向的成本感知視觸覺主動探索/
├── data/               所有專案使用的研究數據
├── doc/                所有專案引用以及創建的文檔                
├── notebooks/          關於功能學習的 jupyter notebooks
├── results/            專案功能的解決方案
├── src/                專案的完整功能實現
└── tests/              單元測試與整合測試
```
